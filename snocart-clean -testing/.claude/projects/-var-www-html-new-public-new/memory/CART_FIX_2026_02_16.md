# Cart Duplicate Items Fix (2026-02-16)

## Problem
Customer #15459 (and 417 others) had **same items appearing multiple times in cart** instead of quantity being updated.

## Root Cause
`CartController::add_to_cart()` returned a `403 error` when an item already existed in cart, instead of updating quantity. This caused:
1. **Race conditions**: Multiple rapid clicks created duplicates
2. **Wrong behavior**: Users expect quantity to increase, not an error
3. **517 duplicate cart records** across 418 customer groups

## Solution Applied

### 1. Fixed Cart Controller Logic
**File:** `app/Http/Controllers/Api/V1/CartController.php:76-115`

**Before:**
```php
if($cart){
    return response()->json([
        'errors' => [
            ['code' => 'cart_item', 'message' => translate('messages.Item_already_exists')]
        ]
    ], 403);
}
```

**After:**
```php
if($cart){
    $new_quantity = $cart->quantity + $request->quantity;

    if($item->maximum_cart_quantity && ($new_quantity > $item->maximum_cart_quantity)){
        return response()->json([
            'errors' => [
                ['code' => 'cart_item_limit', 'message' => translate('messages.maximum_cart_quantity_exceeded')]
            ]
        ], 403);
    }

    $cart->quantity = $new_quantity;
    $cart->save();

    $this->updateCartActivity($user_id, $is_guest, $request->header('moduleId'));

    // Return updated cart...
    return response()->json($carts, 200);
}
```
